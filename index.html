Shyaian Console

A dark, responsive project landing page with a terminal-style demo panel.

  • Repository-style file list
  • Mobile-friendly dashboard
  • Static demo; no messaging backend

To publish, upload the site files to a GitHub repository and enable Settings → Pages.
